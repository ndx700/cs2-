# v0.2 架构

领域模型 → JSON 仓库 → ExplorerState → MainActivity。页面状态增加 `selectedGroupId`，先选择目标组，再选出生位。条目返回时保留父目标；目标返回时回到目标列表。收藏按稳定条目 ID 保存。

三维模型与真实教程参考图分别负责地图导览和精确站位。Mirage LITE 尚未注册到 Source 坐标，所以主页面不把教程坐标强行画到三维模型。原图上的五个编号区域与对应条目绑定，点击直接启动原生播放器。

`TexturedMeshLoader` 在工作线程读取和验证二进制索引网格。`MapRenderer` 在 GL 线程上传贴图，使用深度测试、方向光、mipmap、透明裁切和索引绘制。GL 上下文重建后重新创建着色器和贴图。相机与场景修改通过 queueEvent 调度；静止时不连续渲染。

参考图采用限制下载字节数、超时与图片尺寸的后台加载。回到已选条目时可以看到独立瞄点图和练习坐标。`VideoActivity` 支持自动播放和原教程备用网页；不会在网页媒体地址与直链视频之间自动猜测转换。

`FineMapActivity` 使用 HTTPS 的 Sketchfab 公开嵌入播放器展示精细 CS2 地图。WebView 开启播放器所需的 JavaScript 与 DOM Storage，关闭文件与内容访问，拒绝混合内容，不提供原生 JavaScript 桥，不忽略证书错误。页面链接转系统浏览器；生命周期暂停和释放 WebView。精细模型在线加载，不作为离线资产，底部 VIP 按钮返回主页面对应目标组。

下一阶段：把点击区域配置迁入每个目标的数据、增加图中区域可访问节点、接入等比模型并校准 Source 坐标、增加第一人称站位预览与经过实测的落点。
