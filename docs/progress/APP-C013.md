## 已实施的首批代码

1. `Course`、`CoursePlayer`：统一释放零点与负数准备阶段、站位/瞄点/投法/飞行/结果阶段；相机、人物占位动作、轨迹与效果共用课程秒数。播放/暂停/重播/恢复有显式状态，切视角不改时间。界面提供站位、第一人称瞄点、俯瞰三个手动入口；不声称已经自动编排所有教学镜头。
2. `MapSceneView`、`MainActivity`：开发课入口、准星、播放/暂停/重播/退出，退出恢复浏览相机。后台冻结、恢复不追赶后台时间；Activity 保存课程快照和原浏览相机，GL 重建只重建效果程序。生命周期实际手机验证仍待。
3. `CourseJson` 与 `docs/contracts/C013-course-fx-v1.md`：可替换课程接口，实际 manifest SHA 校验、坐标空间、时间原点、来源、校准标记、有限值/数量/引用校验。可解析开发小样及拒绝播放的 null 正式草稿。该接口是 APP 提案，尚待资源方回执，不代表双方已冻结。
4. `CourseFxRenderer`：烟生长/成型/消散；每个火区独立延迟起燃/熄灭；HE 爆闪/烟尘、局部烟缺口与恢复。按时间解析求值，无跨重播残留粒子；固定32KiB点元缓冲、15KiB人物/轨迹缓冲、<=1024点元，GL线程绘制并恢复混合/深度写入状态。
5. `SmokeGrid` / `GroundFireSchedule`：有界连通查询与地面传播原型，合成墙体阻隔、门洞连通、楼层隔离、晚到区测试通过。尚未接真实沙二碰撞语义或当前视觉效果。
6. 两个明确标为开发演示的样例：DEV-C013-SMOKE-HE 关联 D2-001/D2-014；DEV-C013-FIRE 关联 D2-009/D2-010。全部位置、阶段秒数、范围为实验参数；测试空间在匪家上方，非正式站位。人物当前是脚底圈/简笔骨架占位。
