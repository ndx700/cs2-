## C013-APP — 骨架／功能工程师

负责：Kotlin、UI、教学相机、人物展示、统一课程时钟、轨迹、烟火与 HE 渲染及 Android 性能。

可以立即开始：
1. 实现站位展示 → 第一人称准星／瞄点 → 投法提示 → 预设轨迹 → 落点／动态效果的播放框架，支持第一／第三／上帝视角。
2. 同一课程时钟控制人物动作、轨迹、烟、火和 HE。暂停冻结效果年龄；重播清空旧效果；切换视角不重置阶段。妥善处理后台恢复、GL 上下文重建及线程边界。
3. 在 `docs/contracts/C013-course-fx-v1.md` 提交课程／效果数据字段与小样，覆盖稳定编号、资源版本、坐标空间、时间零点、参考来源、未校准标记、烟阶段、火区延迟及 HE 局部缺口／回填。先做可替换数据接口，不依赖所有素材齐全。
4. 并行做地形约束烟雾原型与地面火原型；首版必须有烟的动态阶段、火的晚着火区域、HE 局部冲烟及恢复。实验参数与未标定地点只作开发验证，不包装成正式课程。
5. 校准包到达后先接 D2-001＋D2-014，再接代表火场景。保留完整地图、触控、加载优化和现有自由视角。

不修改资源方的候选清单、校准记录、地图分卷与资源进度文件。遇资源缺项，在自己的进度文件逐项列出，继续完成不依赖该缺项的框架／原型。

交付：
- 独立代码 PR，注明 C013-APP、基线 SHA、资源依赖、实际测试和未完成项。
- `docs/progress/APP-C013.md`：首次读取后记录权限验证和接单状态，再记录实际实施进度。
- 完整教学录屏；暂停、重播、视角切换检查；烟／火／HE 的动态过程证据。
- 按 AGENTS.md 恢复／校验资源并运行相关单元测试、Lint 和编译。桌面／CI 与 Android 手机结果分开；未连接手机写未测。

## C013-RES — 逆推／资源工程师

负责：课程参考、坐标与几何语义、人物／效果资源、空间覆盖及时间标定。

可以立即开始：
1. 核对 C012 原链接与片段，优先 D2-001、D2-014，其次 D2-009 或 D2-010。提取站位、朝向、瞄点参照、投法、落点／爆点及相应截图，记录视频／地图／游戏版本；获取失败只报告具体缺项，不要求重传全部资料。
2. 提供逐阶段时间表与覆盖范围：烟从起烟至消散；火的初始区、蔓延顺序、晚着火区和熄灭；HE 缺口出现、范围和回填。统一说明时间零点，不能把原视频片段长度当效果寿命。
3. 整理可复用人物姿态、烟火／HE 素材与依赖，给路径、版本、校验值及来源。缺少原运行时逻辑须明确；静态烟火图片不是动态功能交付。
4. 核对完整碰撞输入、表面层及实体覆盖，重点墙体、门洞、地面和上下层。显示预览排除 clip／sky 不等于烟火查询规则。
5. 瀑布烟／挂门烟另交高低差与门洞的参考和空间小样。真实位置未确认先交查询基础、坐标约定及待补表，不伪造课程地点。
6. APP 接口未定稿时先交来源／测量表；按 `docs/contracts/C013-course-fx-v1.md` 适配可导入校准包。坐标空间和单位显式标注，转换只做一次。

不修改 APP 的 Kotlin、课程时钟和渲染代码，也不修改 APP 的接口文件。候选元数据由资源侧在自己的 PR 更新；待测值保持 null／待校准。

交付：
- 独立资源 PR，注明 C013-RES、基线 SHA、地图／资源版本、来源及校验。
- `docs/progress/RES-C013.md`：首次读取后记录权限验证和接单状态，再记录实际实施进度。
- `docs/calibration/C013/` 下提交参考截图索引、时间／空间测量表、坐标说明和具体缺项。
- 资源内容变更按 AGENTS.md 重新打包并校验；不直接编辑分卷，不上传未经处理的大体积原始素材或 APK 到普通代码提交。

- 两边分别提交小步、可审查的 PR，不等待 14 条课程全部完成才交付。
- 项目经理核对接口、来源、资源版本、CI 和动态验收证据；不代替两位工程师写“已开工”。

- 更新各侧独立进度，整合后由项目经理更新 STATUS。状态沿用 RECEIVED → IN_PROGRESS → READY_FOR_INTEGRATION → INTEGRATED → VERIFIED；具体依赖未满足写 BLOCKED。
