# CS2 沙二第二版完整道具教学施工文档

C014   一个烟 一个火 一个雷   2026年10月4日

## 今晚交付范围

交给 APP 工程师与资源工程师执行。今晚第二版集中做完三个可学习、可复播的课程。用户应能看懂在哪里站、瞄哪里、怎样投、落在哪里，以及落地后起什么作用。交付目标为北京时间 2026年10月4日晚，按本文件逐项验收后交付 APK。

### 三个课程

| 编号 | 内容 | 用户必须看见 |
| --- | --- | --- |
| D2-001 | T出生至中门烟 | 站位和第一人称瞄点；烟在中门起烟、成型、封住视线并消散。 |
| D2-010 | A大 Car 火 | 真实站位和投法；落地破裂、车位起火、向车后蔓延并熄灭。 |
| D2-014 | CT 炸中门烟 HE | 烟先成型；雷飞入、爆炸、局部烟被冲开、出现缺口，再回填。 |

### 每个课程的完整播放流程

进入课程先展示第三人称站位和附近参照物，再切第一人称准星与瞄点，显示投掷方式，然后播放出手和飞行。主画面跟随道具，右侧窗口同步观察落点；落地后两处画面都能看见动态效果。最后显示用途和结果。

用户可暂停、重播、切换站位／瞄点／跟随视角，并直接跳到落点效果。阶段名称使用中文，不能要求用户理解内部状态或自己猜该点哪里。

### 当前问题与完成边界

用户实测只看见小人向上扔东西，没有看见烟雾和燃烧效果。现有开发样例和地图读取修复不能算三个正式课程验收通过。APP 工程师先定位镜头、效果显示、时间轴或数据接入的具体原因，再按下面的可见结果修复。

本批次先收口这三个课程；沿用已有沙二地图、加载优化和触控。预设轨迹、预设动作与效果动画可以使用，人物可简化，但必须清楚呈现站位、朝向和出手。课程坐标、瞄点、落点及效果时序须对照参考校准。

## 镜头和动态效果

镜头必须主动把教学对象放在可见位置。烟、火、爆炸和炸烟缺口必须在实际 APK 中看得见，不能只在代码、参数说明或静态截图中存在。

### 主画面跟随道具

出手前先看清人物与瞄点；飞行期间镜头跟着道具移动，始终能看见道具及它前方的地图环境，不能只画一条线。到达落点或爆点后，镜头稳定观察结果。镜头不能钻进墙体、地面或烟体后导致效果看不见。切换视角保持当前播放进度。

### 右侧实时落点窗口

教学时固定显示在右侧，窗口标题为“落点实时演示”。投掷前标出目标位置；飞行时仍盯住目标；落地后继续显示烟、火或爆炸的变化。它与主画面使用同一课程时钟，暂停同时冻结、重播同时清空旧效果，不能使用循环视频冒充当前投掷的结果。

落点／爆点名称与覆盖边界可显示、可隐藏；覆盖标记不能代替动态效果。竖屏也要能辨认中门、车位及效果，点按窗口可放大后返回。横竖屏切换保留播放状态，窗口不得遮住准星、投法说明和主要操作。

### 三种效果的验收内容

| 道具 | 动态过程 | 观察重点 |
| --- | --- | --- |
| 烟 | 落地起烟 → 扩散 → 成型维持 → 消散 | 看见烟体遮挡目标视线；贴合门洞及附近地形，边界有变化。 |
| 火 | 破裂 → 初始着火 → 分区蔓延 → 持续燃烧 → 熄灭 | 看见地面火焰，能区分初始区域与稍后才烧到的区域。 |
| 雷 | 飞行 → 指定爆点爆炸 → 局部冲烟 → 缺口 → 回填 | 看见爆炸和受影响区域；只冲开局部烟，随后恢复。 |

### 参考和时序

逐阶段核对参考画面，记录时间零点、起效时间、主要覆盖范围与消散／熄灭时间。未核实的真实秒数、伤害值和物理参数不得填成确定事实。可以减粒子和细节保证流畅，但要保留上述动态阶段及晚起火、缺口回填的先后关系。

## 两位工程师的施工分工

两侧从开工时最新 main 建各自任务分支，保留已合并的地图分块加载兼容修复。现有 APP PR 5 和资源 PR 4 可作为候选成果复用，先核对实际内容和依赖，按三个课程联调交付。

### APP 工程师

负责教学入口、中文阶段提示、人物站位与出手、第一人称瞄点、道具跟随相机、右侧落点窗口、烟火和 HE 渲染，以及暂停、重播、跳到效果、视角切换与生命周期恢复。先用明确标记的联调数据把显示链路跑通，再接入资源方的三个课程。

优先解决用户看不见效果的问题。两个画面共享时间和效果状态；避免同时重复解压地图或建立两套加载队列。后台恢复、屏幕旋转和 GL 上下文重建后不得出现旧烟残留、时间跳变、空白落点窗口或持续重复请求。

### 资源工程师

按 D2-001、D2-010、D2-014 提供真实站位截图、第一人称瞄点截图、投法、轨迹关键点／反弹点、最终落点／爆点，以及逐阶段效果与覆盖参考。核对地图资源版本、坐标空间、人物脚底和眼睛位置。瞄点参照物必须在手机地图纹理中可辨认，辅助提示可隐藏。

参考访问失败时，列明哪一条、哪张图或哪个参数缺失，并先交已核实的数据。沿用用户已给的参考及编号，不重新让用户提交整套材料。未校准项留在开发入口，不能把空中测试坐标作为真实站位交付。

### 共同交付数据

沿用 C013 课程与效果契约。每课至少包含编号、用途、地图／资源版本、校准状态与证据；脚底／眼睛／瞄点坐标、朝向和投法；带时间的轨迹节点及落点／爆点；各效果事件与覆盖范围；站位、瞄点、跟随及落点观察所需的相机信息。

时间统一以道具释放为零点，视频中的片段定位与课程效果时间分别记录。D2-014 引用同一中门烟场景，保证烟先成型再炸烟。数据字段变更两侧同时对齐，不让 APP 静默忽略缺失字段。

### 今晚执行顺序

第一步，两侧记录接单及具体缺项，确认三个课程和数据接口。第二步，先贯通中门烟与 HE 炸烟，APP 同时完成两种观察画面，资源方同步交车位火。第三步，联调三个完整课程并录制手机验收证据。第四步，项目经理核对证据、打包与签名后交付 APK。

进度只报告已做出的结果、剩余阻塞和下一次可交付内容。资料和文档完成、编译成功均不能替代手机上的课程效果验收。其他会话是否开始执行，以其接单记录为准。

## 交付验收和参考入口

第二版完成以三个课程在手机中连续演示成功为准。用户应能直接安装、直接进入课程学习，无需先安装旧版或寻找隐藏开发入口。

### 逐项验收

1  地图正常显示；三个课程入口清楚，名称、用途和投法可读。

2  站位脚底贴合地面；真实第一人称准星与参照物对应；隐藏提示后仍能辨认瞄点。

3  主画面跟随道具；右侧窗口实时看落点；两个画面都能清楚看见效果，不被墙体或镜头遮挡。

4  烟起烟至消散、火延迟蔓延至熄灭、HE 局部炸烟至回填全部可见；效果范围对应参考。

5  暂停冻结、重播复现、切换视角保持进度；后台返回及横竖屏切换后仍正常。

6  保留地图与贴图最终包校验、相关单元测试、Lint 和 APK 构建检查；手机性能记录机型和真实观察结果。

### 本批次必须交付

可浏览器下载的完整 APK，记录版本、来源提交、文件大小及 SHA256；应用包名及签名保持覆盖安装兼容，版本号提高。三个课程各提供一段从站位至效果结束的手机录屏；另附暂停、重播与视角切换证据、三课校准数据和实际测试记录。

任何未通过项目写明课程编号、触发步骤和缺项；没有效果录屏或没有校准证据的课程继续标待验收。交付时把 APK 链接单独发给用户，并给出三个课程的进入路径。
