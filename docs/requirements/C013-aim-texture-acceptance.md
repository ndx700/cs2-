# C013 教学瞄点区域贴图精度验收补充

日期：2026-10-04（北京时间）。发布者：项目经理。范围：当前 C013 正式教学课程。
用户原文：[教学瞄点区域贴图精度补充要求](../sources/C013_教学瞄点区域贴图精度补充要求.docx)。
本文件把用户要求转为两位工程师的执行安排，补充 C010、C012 和 C013；需求登记不代表实现或验收通过。

## 当前必须执行的要求

覆盖 D2-001～D2-014，先在 D2-001、D2-014、D2-009、D2-010 校准时执行。检查玩家站位与脚部接触区域、第一人称瞄点，以及周围足以识别位置的墙缝、污点、裂纹、箱角、门框和几何边缘。

地图整体继续使用移动端优化资源。只有影响教学的区域才提高分辨率、重新裁切或制作、修正 UV。不要无差别升级整张地图。一个世界坐标或一个辅助标记不能证明课程可复现；用户必须能在真实 CS2 场景中辨认同一参照物。

## 两位工程师的交付

| 负责侧 | 要做的事 | 提交证据 |
| --- | --- | --- |
| 资源工程师 | 对照 CS2 实机检查站位、瞄点周边纹理与几何；有问题则局部精修；记录资源版本、UV／材质变化和来源 | 每条课程的参考截图、APP 对照截图索引、修正清单、版本与校验值；未获得参考的条目标待补 |
| APP 工程师 | 在第一人称教学中提供短暂小圆圈、标记或局部放大提示，并支持淡出或隐藏；隐藏后仍能依靠真实纹理完成对点 | 同一课程显示提示和隐藏提示后的手机截图／录屏，说明构建、资源版本、视角与画质设置 |
| 项目经理 | 人工审查实现、两侧版本与证据，逐条确认 CALIBRATED 条件 | 验收记录、未通过原因和补齐任务 |

项目经理建议用同一站位、朝向和可比较的第一人称视野保存 APP 与 CS2 实机对照图，记录分辨率和视野设置，避免仅凭两张取景不同的图片认定偏差。这是执行建议；必须满足的清晰度标准来自用户原文。

## CALIBRATED 新增通过条件

以下条件须同时满足：

1. 站位参照物清楚，玩家脚部和墙／箱接触关系可辨认。
2. 第一人称准星附近的真实瞄点参照物清楚，周边区域足以定位。
3. APP 与当前 CS2 实机参考没有影响教学的明显纹理或位置偏差。
4. 手机实际显示仍能辨认瞄点；关闭辅助提示后可依靠真实纹理找到它。
5. 课程记录关联实际 APP 构建、地图／资源版本及参考来源；原有站位、投法、落点和动态时间校准条件仍有效。

缺少实机参考或手机验证时写待补／未测，不能仅因代码存在、坐标已填或 CI 通过就标 CALIBRATED。不满足时先修正该课程局部资源／教学画面，再复验；独立框架开发继续进行。

## 逐条记录字段

课程编号、地图和资源版本、APP 构建、CS2 地图／游戏版本（未知写待补）、参考来源与时间点、站位／朝向／视野、关键参照物说明、两侧截图索引、辅助提示关闭后的画面、手机设备及显示设置、检查结果、问题和负责侧。

资源侧在自己的 `docs/calibration/C013/` 记录校准材料并更新 `docs/progress/RES-C013.md`；APP 侧更新 `docs/progress/APP-C013.md`。沿用各侧任务分支与 PR，不同时修改对方的进度文件。
