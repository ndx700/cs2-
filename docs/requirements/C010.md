## 2. 三类动态效果的实现与验收边界

### 烟雾弹

可见过程：落点起烟 → 烟体增长 → 向周围扩散 → 基本／完整成型 → 稳定维持 → 逐渐消散。

每条烟记录投掷、落地、起烟、基本成型、完整成型、维持时长以及消散起止时间。具体数值从对应实机视频标定；没有证据时写“待测”，不能填入推测的统一秒数。

允许粒子、噪声、体积近似、多层 Billboard 和预设动画组合。动态烟须位于同一地图世界内，切换第一人称、第三人称和上帝视角时观察到同一位置、阶段和覆盖范围。单张固定烟图突然出现不能通过验收。关键教学场景需检查墙边、门洞、不同高度以及烟内／烟外的可见表现，避免明显穿墙和悬空。

### 燃烧弹／燃烧瓶

可见过程：落地／破裂 → 初始着火区域 → 向相邻区域铺开 → 最终覆盖 → 持续燃烧 → 逐渐熄灭。

每条火记录初始落点、第一批着火区域、蔓延方向及顺序、各区域开始燃烧时间、最终覆盖、持续时长和熄灭过程。可使用预设蔓延节点或区域时间偏移。选取至少一个“初始无火、随后着火”的位置作为首版验收点，不能仅缩放一张最终覆盖图来代替过程。火焰在区域燃烧期间持续变化，贴合有效地面；具体蔓延和持续时间由对应实机录像标定。

### HE 爆炸与炸烟

独立爆炸必须呈现爆点、短暂火光／冲击、烟尘和快速衰减。

炸烟必须演示：烟已经成型 → HE 在烟内或附近爆炸 → 局部烟被短暂冲开 → 出现可观察缺口 → 烟重新填回。缺口范围、打开时刻和回填过程绑定真实 CS2 参考片段；不能把整团烟直接删除，不能把缺口永久保留。

首版允许局部遮罩、预设形变和粒子驱散／恢复动画，不要求完整烟体流体响应。HE 和烟共享同一课程时间轴，暂停、重播、切换视角后交互状态必须一致。

## 3. 教学播放流程继续执行 C009

1. 第三人称显示人物脚下位置、朝向以及贴墙／贴箱关系。
2. 拉近关键站位参照物，保证箱角、墙缝、砖纹或标识可看清。
3. 切换第一人称，显示准星和经参照确认的瞄点。
4. 提示对应投掷方式：站投、跑投、跳投等，以实际资料为准。
5. 播放人物投掷动作及预设轨迹；动作和轨迹使用同一时间轴。
6. 跟随落点或切换上帝视角查看落地／爆点。
7. 播放动态烟、逐步蔓延的火或 HE 爆炸／炸烟。
8. 支持暂停、重播以及第一／第三／上帝视角切换。

暂停须冻结课程事件与效果年龄；重播须清理旧轨迹、火区、烟体和 HE 缺口再从起点恢复。自由观察镜头不能代替已标定的正式瞄点镜头。站位、瞄点、投掷方式和落点仍需与实战参考匹配。

## 4. 候选道具母库与用户筛选

- 每条分配稳定编号，例如 D2-001、D2-002。筛选后不重排编号，不复用已删除编号。
- 至少记录类型、T／CT、用途、起始站位、第一人称瞄点、投掷方式、落点／爆点／覆盖、参考视频及来源。
- 相同目标的不同投法尽量连续展示，便于对比；编号身份保持不变。
- 初始筛选状态为“待定”。用户按编号口述“留／删／待定”，项目经理记录决定及原因；不自行删除。
- “删”从正式导入候选中排除，保留母库记录供追溯。最终用户“留”的清单作为正式导入清单；资料未标定的条目另标“待校准”，不能伪装成可用课程。
- 筛选 Word 每条包含：编号、类型、用途、站位截图及短说明、准星瞄点截图及参照说明、投掷方式、落点与动态时间轴、留／删／待定选项。

站位／瞄点可以参考道具数据库；烟、火、HE 的最终动态视觉和时间必须额外绑定 CS2 实机录像。分开记录“教学来源”和“效果来源”，不能把网页模拟器效果当作实机视觉标准。

每段效果参考需能追溯到视频／文件、片段时间、地图和游戏版本信息（未提供则标待补）。时间轴应明确零点，例如投掷释放时刻；记录逐阶段相对时间和对应视频时间，避免把录像进度条秒数直接用作动画年龄。本次附件没有实机录像，不得生成虚构站位、瞄点或时间数据。
