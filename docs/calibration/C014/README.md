## 接口与镜头联调

- 基础接口沿用 APP PR #5；本轮已读取 APP PR #10 head `346c20fc5d36654b9ce7ca6bbfe956000780d428` 的 C014 补充合同、CourseJson 与 Course 校验源码，并在 `app-observation-receipt.json` 绑定各文件 blob SHA。资源侧接受新增五镜头槽位与主投掷释放零点规则；该回执只确认字段和约定，不表示真机或课程校准通过。
- follow/landing 是轨道镜头：position 是观察目标，不能直接当相机眼位。distance 至少 1 显示单位，pitch 为 20～85 度；follow 的动态目标由 APP 在出手前/飞行中/落地后分别选择 eye/道具/最后轨迹点，landing 固定目标。两项不能凭 overview 开发默认值晋升为正式镜头。
- 显示坐标 Source `(x,y,z)` → `(0.0254*x,0.0254*z,-0.0254*y)`，只转换一次。APP 名称 `display-m-y-up-v1` 仅作字段别名；原命令不等于脚底或眼位，向下碰撞命中也不证明教学站位。
- 右侧窗口需求是“落点实时演示”；主画面飞行时跟随道具、起效后稳定看结果。三课均记录这两种观察角色，但没有凭未知落点编造相机位置。镜头是否穿墙和竖屏是否可辨认由 APP 手机证据确认。
